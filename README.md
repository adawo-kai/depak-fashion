# DEPAK.fashion

Лендинг бишкекского бренда одежды для горных походов. Astro, статическая сборка, без UI-фреймворков.

## Запуск

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
```

## Структура

- `src/data/site.ts` — контакты, товары, категории, слайды. Править контент здесь.
- `src/components/` — секции страницы.
- `src/scripts/` — слайдер hero (`hero.ts`), корзина (`cart.ts`), меню и анимации (`ui.ts`).
- `public/img/` — фотографии (Unsplash, свободная лицензия). Замените на свои с теми же именами.

## Как это работает

- **Корзина** хранится в `localStorage`; кнопка «Оформить» открывает WhatsApp с готовым списком заказа.
- **Форма обратной связи** отправляется через [FormSubmit](https://formsubmit.co) на почту из `site.ts`. При первой отправке на почту придёт письмо с подтверждением, его нужно активировать один раз.

## Деплой

Vercel определяет Astro автоматически: Framework Preset — Astro, команда `npm run build`, папка `dist`.
